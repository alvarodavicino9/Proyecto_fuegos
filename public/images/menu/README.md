# Fotos del menú

Cuando el dueño confirme fotos en buena calidad, guardalas acá con un nombre
descriptivo (ej. `doble-cheddar.jpg`) y en `src/data/menu.ts` completá el
campo `image` del producto correspondiente, por ejemplo:

```ts
image: '/images/menu/doble-cheddar.jpg',
```

Mientras no haya foto, la tarjeta del producto muestra un fondo decorativo
con el estilo de marca (sin necesidad de imagen).
