# Logo e identidad de marca

Cuando tengan los archivos originales del logo (dorado y el ícono de
llama) en buena resolución, guardalos acá, por ejemplo:

- `logo-gold.png` — logotipo dorado "Fuegos"
- `logo-flame.png` — isotipo de llama

Después reemplazamos el componente `src/components/brand/Logo.tsx` (que hoy
recrea el logo en código/CSS) por las imágenes reales, y actualizamos
`public/favicon.svg` si quieren el ícono de llama original como favicon.
